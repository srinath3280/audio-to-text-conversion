<!-- Project Running Commands -->

<!-- For Client file -->

1. Open Termainal
2. In Terminal Select [Command Prompt]
3. Change the root directory to [client]
4. Enter command [npm install] for required libraries installion
5. Start the project using this command [npm start]


<!-- For server file -->

1. In the same Termainal
2. Select one more [Command Prompt]
3. Change the root directory to [server]
4. Enter command [npm install] for required libraries installion
5. Start the project using this command [nodemon server.js / npx nodemon server.js]


<!-- For pythonserver file -->

1. In the same Termainal
2. Select one more [Command Prompt]
3. Change the root directory to [pythonserver]
4. Enter command [python -m venv venv] to create a virtual environment
5. After Created virtual environment enter command [venv\Scripts\activate.bat] to activate the VE
6. Later enter command [pip install -r requirements.txt] for installing required modules/libraries
7. Later enter command [uvicorn server:app --reload] to start the python server


Note:

All three files are running successfully then only get a proper output.
